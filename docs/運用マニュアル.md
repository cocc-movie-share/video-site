# 運用マニュアル（管理者向け）

パソコンやスマホのブラウザだけで操作できます。プログラムの知識は不要です。

## 管理画面に入る

1. https://cocc-movie-share.github.io/video-site/administrator/ を開く
2. 管理者パスワードを入力して「ログイン」
3. 2 時間たつか、タブを閉じると自動でログアウトします

## 動画をアップロードする

1. 「大会・イベント」を選ぶ
   - 新しい大会のときは「＋ 新しい大会・イベントを追加」を選び、名前を入力（例：`2027茅ヶ崎レース`）
2. 「チーム」を選ぶ
   - チーム分けしない動画（体験会など）は「チームなし」
   - 新しいチームは「＋ 新しいチームを追加」を選んで名前を入力
3. 「動画ファイル」で mp4 / mov を選ぶ（複数まとめて選べます）
4. 「アップロード」を押す。すべて「完了」になるまで画面を閉じないでください

- 1 本の上限は 2GB です
- 同じ大会・チームに同じファイル名の動画があるとアップロードできません。ファイル名を変えてください
- サムネイル（一覧の画像）は自動で作られます。iPhone で撮った一部の mov など、ブラウザで再生できない形式はサムネイルが付きません

## チームを間違えたとき（動画の移動）

1. 「動画の管理」で大会を選ぶ
2. 動画の横のプルダウンで正しいチームを選ぶ
3. 「移動」を押す

## 動画を削除する

「動画の管理」で大会を選び、動画の「削除」を押す → 確認で OK。**元に戻せません。**

## 大会・チームの名前を変える

「大会・イベント」または「チーム」の一覧で「名前を変更」を押し、新しい名前を入力します。

- 中の動画もすべて新しい名前の場所へ移動します。本数が多いと時間がかかるので、終わるまで画面を閉じないでください
- 途中でエラーになった場合は、もう一度同じ名前で変更すると続きから再開します

## 大会・チームを削除する

一覧の「削除」を押します。動画が 1 本でも残っていると削除できません（先に動画を移動・削除してください）。

## 名前に使えない文字

`/` `\` と、先頭の `.` は使えません。50 文字までです。

## パスワードを変えたいとき

PC での作業が必要です。[デプロイ手順.md](デプロイ手順.md) の「パスワードを変えたいとき」を参照してください。
閲覧パスワードを変えたら、メンバーに新しいパスワードを伝えてください。

## 困ったとき

| 表示 | 原因と対処 |
|---|---|
| 試行回数が多すぎます | パスワードを 1 分に 5 回以上間違えました。1 分待ってから再度ログイン |
| ログインが必要です | ログインの期限切れです。ページを再読み込みしてログインし直す |
| 動画ファイル（mp4 / mov）ではない | 拡張子だけ変えたファイルなどです。元の動画ファイルを選び直す |
| Failed to fetch | 通信できていません。電波を確認して再度お試しください |
