# デプロイ手順

## 画面（GitHub Pages）

`main` にマージすると自動で公開されます。作業は不要です。

- 公開先：https://cocc-movie-share.github.io/video-site/
- 管理画面：https://cocc-movie-share.github.io/video-site/administrator/
- 状況確認：リポジトリの「Actions」タブ

## API（Cloudflare Worker）

初回だけ PC で行います。Node.js（LTS）が必要です。

### 1. 準備

```bash
cd worker
npm install
npx wrangler login   # ブラウザが開くので Cloudflare にログインして許可
```

### 2. 秘密情報を登録

1 つずつ実行し、聞かれたら値を入力します（画面には表示されません）。

```bash
npx wrangler secret put VIEWER_PASSWORD
npx wrangler secret put ADMIN_PASSWORD
npx wrangler secret put TOKEN_SECRET
```

`TOKEN_SECRET` には長いランダムな文字列を使います。次のコマンドで作れます。

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

### 3. 公開

```bash
npm run deploy
```

表示された URL（現在：`https://cocc-video-site-api.manato-inokuchi.workers.dev`）を `site/js/config.js` の `API_BASE_URL` に書き、PR を作ってマージします。

### パスワードを変えたいとき

手順 2 の該当コマンドをもう一度実行するだけです。再デプロイは不要です。
`TOKEN_SECRET` を変えると、全員が自動的にログアウトされます。

## ローカルで試す（開発者向け）

```bash
cd worker
cp .dev.vars.example .dev.vars   # 値を書き換える（Git には入らない）
npx wrangler dev
```
